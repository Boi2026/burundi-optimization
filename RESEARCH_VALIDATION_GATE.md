# BOI Research Validation Gate

## Project
Agricultural Supply Network Optimization in Burundi

## Gate objective

Determine whether the current computational model can be supported by sufficiently documented empirical evidence.

## Required evidence

- [ ] authoritative network/road data or documented field data
- [ ] source provenance
- [ ] observation/reference date
- [ ] parameter definitions
- [ ] unit consistency
- [ ] missing-data treatment
- [ ] baseline comparison
- [ ] validation metric(s)
- [ ] sensitivity analysis
- [ ] reproducible scripts
- [ ] machine-readable outputs

## Decision states

### NOT READY
Evidence required for validation is missing or insufficient.

### PARTIALLY VALIDATED
Some components have empirical support, but the complete model is not validated.

### VALIDATED FOR SPECIFIC USE
A clearly bounded experiment has passed its stated validation criteria. This does not imply universal validity.

## Integrity rule

Do not convert a model assumption, estimate or synthetic scenario into an empirical claim without supporting evidence.
