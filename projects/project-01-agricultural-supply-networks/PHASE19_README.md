# BOI Project 1 — Phase 19
## Empirical Data Intake & Integration

**Status:** Integration framework ready — awaiting real observations.

Phase 19 defines the controlled pipeline from external observations to a frozen, BOI-matched empirical dataset.

### Scope
- ingest real observations;
- preserve raw values;
- standardize units and currencies only with documented rules;
- match markets, products and corridors to BOI entities;
- identify duplicates and anomalies;
- maintain an unmatched/review queue;
- produce an auditable integration manifest.

**No synthetic empirical observations are permitted.**

### Gate
Phase 20 empirical validation remains blocked until a documented empirical dataset passes Phase 19 QA and is frozen.
