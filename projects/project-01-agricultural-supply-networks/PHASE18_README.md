# BOI Project 1 — Phase 18
## Empirical Data Acquisition & Validation Execution Plan

**Scientific status:** Acquisition-ready — no empirical observations are fabricated.

### Objective
Obtain a traceable set of real-world observations needed to move BOI Project 1 from analytical screening to empirical validation.

### Required evidence streams
1. Transaction/market prices
2. Freight tariffs and/or observed transport costs
3. Road accessibility / travel-time observations
4. Supply and demand observations
5. Transport cost components

### Minimum governance rule
Every observation must have:
- unique observation_id
- source
- observation date
- geography/market/corridor
- product or cost category where applicable
- original unit
- raw value
- standardized value
- evidence/reference
- matching status
- QA status

### Prohibited
- synthetic observations presented as empirical data
- invented freight tariffs
- invented supply/demand quantities
- backfilling missing observations with model outputs
- declaring empirical validation before Phase 20
