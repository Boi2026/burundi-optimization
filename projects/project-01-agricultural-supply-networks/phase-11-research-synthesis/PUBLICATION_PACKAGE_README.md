# BOI Project 1 --- Publication Package

This folder contains the synthesis layer for the completed Phases 1--10.

## Recommended public-facing outputs

-   `PHASE11_RESEARCH_SYNTHESIS.md` --- integrated research narrative
-   `KEY_FINDINGS.csv` --- machine-readable summary of principal
    indicators

## Recommended positioning

Present the project as a **graph-based and optimization-oriented
analytical framework for agricultural market connectivity in Burundi**.

Avoid claims that the model observes actual trade volumes, actual
freight flows, realized arbitrage, causal price transmission, or
investment returns.

The principal contribution is the integration of market-price
information, network distances, transport-cost sensitivity, robustness
analysis and multi-product corridor screening.

## Next research stage

Focus on empirical validation and data enrichment: - observed freight
tariffs, - supply/demand quantities, - vehicle capacities, -
road-condition data, - seasonal accessibility, - and field validation of
priority corridors.
