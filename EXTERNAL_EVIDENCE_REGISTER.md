# BOI External Evidence Register

Purpose: maintain an auditable record of independent public evidence supporting BOI's existence, activity and research relevance.

## Verified public signals

| Evidence | Status | Interpretation |
|---|---|---|
| Public GitHub repository | Verified | BOI has a public technical/research repository. |
| GitHub account appears in a public Burundi developer ranking | Verified externally | Independent public infrastructure currently lists Boi2026 and identifies it as Burundi Optimization & Intelligence (BOI). |
| Public research repository with versioned materials | Verified | BOI exposes research documentation and methodology. |
| Public website declared in repository | Present | Website is part of BOI's public architecture; live/indexing status should be checked separately. |

## Evidence standard

An external mention is not treated as institutional endorsement. It is only evidence that an independent public source recognizes or indexes BOI.

## Next evidence targets

1. Search-engine indexing of the official domain.
2. Independent citations or references to BOI research.
3. Research collaboration records.
4. Public talks, workshops or technical presentations.
5. Persistent research identifiers where appropriate (e.g. DOI for a finished research output).
6. External institutional or academic references that can be independently verified.

## Prohibited shortcuts

Do not manufacture endorsements, affiliations, citations, testimonials, conference roles, publication claims or institutional partnerships.
