# BOI Professional Web Platform

Next.js 16 foundation for Burundi Optimization & Intelligence (BOI).

## Included
- Professional BOI landing page
- Flagship Project 1 research page
- Results and methodology sections
- Six research workstreams
- Dynamic Phase 01–44 research records
- Conservative validation-status language
- Responsive CSS without external UI dependencies

## Vercel
Import the repository root. Once `package.json` is present, Vercel should detect Next.js and use framework-aware defaults.

Recommended release flow:
- `main` → Production
- feature branches / pull requests → Preview
- custom domain only after Preview QA

## Scientific disclosure
This web layer does not upgrade the scientific status of the underlying work. Project 1 remains analytically finalized/reproducible but not empirically validated; recalibration remains blocked pending sufficient primary observations and independent holdout validation.
